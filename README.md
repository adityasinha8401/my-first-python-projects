## 🎮 Project 1: Guess the Number Game
A beginner-friendly console game where the user guesses a computer-generated secret number. 
### 🧠 Core Concepts Practiced:
While Loops: To keep the game running until the player wins.
Conditional Logic: Using `if-elif-else` to give higher or lower hints.
Random Module: Using `random.randint` to pick dynamic numbers.
